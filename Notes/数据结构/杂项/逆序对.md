# 逆序对 (Inversion Count)

**定义**：$i < j$ 且 $a[i] > a[j]$，则 $(i, j)$ 是一个逆序对。求总数。

**例题**：P1908 逆序对，$n \le 5 \times 10^5$。

---

## 方法 1：归并排序 $O(n\log n)$

### 思路

归并时左右两半各自已有序。当**右半元素被取走**时，说明左半**当前及之后所有元素**都大于它，都构成逆序对。

```
左: [2, 5, 8]    右: [1, 3, 7]
     ↑                 ↑
   2 > 1 → 1 比 2,5,8 都小 → 贡献 3 个逆序对，1 归位
        2 < 3 → 不贡献，2 归位
           5 > 3 → 贡献 2 个（5,8 对 3），3 归位
```

### 代码

```cpp
int a[N], b[N];
ll ans;

void mergesort(int l, int r) {
    if (l == r) return;
    int m = l + r >> 1;
    mergesort(l, m);
    mergesort(m + 1, r);
    int i = l, j = m + 1, k = l;
    while (i <= m && j <= r) {
        if (a[i] <= a[j]) b[k++] = a[i++];          // 相等取左边，不算逆序对
        else b[k++] = a[j++], ans += m - i + 1;      // 右边小，左半从 i 到 m 都是
    }
    while (i <= m) b[k++] = a[i++];
    while (j <= r) b[k++] = a[j++];
    for (int ii = l; ii <= r; ii++) a[ii] = b[ii];
}
```

### 关键细节

- `a[i] <= a[j]` 用 `<=`，**相等不算逆序对**
- `k = l`（不是 `k = r`！），临时数组从区间起点开始填
- `ans` 用 `long long`，$n=5\times10^5$ 最坏约 $1.25\times10^{11}$

## 方法 2：树状数组（BIT）$O(n\log n)$

### 思路

从左到右遍历，BIT 当**值域桶**用——存「每个值出现了几次」。

走到 $a[i]$ 时：
- BIT 里是前 $i-1$ 个元素
- `query(a[i])` = 前面 ≤ a[i] 的个数
- $i$ − `query(a[i])` = 前面 > a[i] 的个数 = 逆序对贡献

### 离散化

值域可能到 $10^9$，BIT 下标只能 $[1, n]$，需要把值映射到排名：

```
原数组: [500, 3, 500, 99999, 8]
排序去重: b = [3, 8, 500, 99999]
映射: 500→3, 3→1, 500→3, 99999→4, 8→2
结果: [3, 1, 3, 4, 2]
```

离散化后值域 $[1, m]$，$m \le n$，BIT 开 $n+5$ 即可。

```cpp
vector<int> a(n), b;
for (int &x : a) cin >> x;
b = a;
sort(b.begin(), b.end());
b.erase(unique(b.begin(), b.end()), b.end());
// 映射到 1-index
for (int &x : a)
    x = lower_bound(b.begin(), b.end(), x) - b.begin() + 1;
```

### BIT 部分

```cpp
int lowbit(int x) { return x & -x; }

void add(int x, int k) {
    while (x <= n) cnt[x] += k, x += lowbit(x);
}

ll query(int x) {
    ll r = 0;
    while (x >= 1) r += cnt[x], x -= lowbit(x);
    return r;
}

// 主逻辑
ll ans = 0;
for (int i = 0; i < n; i++) {
    ans += i - query(a[i]);    // i = 已插入总数，减去 ≤a[i] = 大于 a[i] 的个数
    add(a[i], 1);              // 把自己放进桶
}
cout << ans;
```

### 逐帧理解

```
数组: [5, 3, 6, 1]
             ↑ 走到这里

BIT 里存的（已看过）: {5, 3}
值桶:  1  2  3  4  5  6
次数:  0  0  1  0  1  0

query(6) = 2  → ≤6 的有 2 个
i = 2         → 总共看了 2 个（不计当前）
i - query(6) = 0 → 没有比 6 大的 ✅

走到 a[3]=1 时:
BIT 里: {5, 3, 6}
query(1) = 0  → ≤1 的有 0 个
i = 3         → 3 - 0 = 3 个比 1 大的 ✅
```

## 两种方法对比

| | 归并排序 | BIT |
|---|---------|-----|
| 时间 | $O(n\log n)$ | $O(n\log n)$ |
| 空间 | $O(n)$ | $O(n)$ |
| 需要离散化 | 不需要 | 需要 |
| 支持区间查询 | 不支持 | 支持（+ 莫队） |
| 代码量 | ~15 行 | ~30 行 |
| 常数 | 小 | 较大 |

---

## 区间逆序对（扩展）

多次查询任意 $[l, r]$ 的逆序对数，用 **BIT + 莫队算法**。

维护窗口 $[L, R]$，BIT 维护窗口内值的分布：

| 指针移动 | BIT 操作 | 逆序对变化 |
|----------|---------|-----------|
| L 左移（加入左边） | `add(x, 1)` | `ans += query(x - 1)` |
| L 右移（删除左边） | `add(x, -1)` | `ans -= query(x - 1)` |
| R 右移（加入右边） | `add(x, 1)` | `ans += tot - query(x)` |
| R 左移（删除右边） | `add(x, -1)` | `ans -= tot - query(x)` |

复杂度 $O((n+q)\sqrt{n}\log n)$，$tot$ 为当前窗口内元素个数。
