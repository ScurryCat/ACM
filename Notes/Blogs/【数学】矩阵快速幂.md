# 矩阵快速幂：从线性递推到 $O(\log n)$

## 从斐波那契数列说起

斐波那契数列的定义很简单：

$$
F_0=0,\qquad F_1=1,\qquad F_n=F_{n-1}+F_{n-2}\quad(n\ge 2)
$$

按照定义递推，求出 $F_n$ 需要进行 $n$ 次左右的计算，时间复杂度是 $O(n)$。当 $n$ 只有几百万时，这种做法足够快；但如果 $n$ 达到 $10^{18}$，逐项递推就不现实了。

问题的突破口在于：斐波那契数列每向后推进一项，使用的都是同一条转移规则。如果能把这条规则写成矩阵，就可以把“执行 $n$ 次转移”改写成“求一个矩阵的 $n$ 次幂”，再用快速幂把复杂度降到 $O(\log n)$。

矩阵快速幂本身并不神秘。它就是普通二进制快速幂，只不过把数字乘法换成了矩阵乘法。真正需要花心思的地方，是如何把递推关系翻译成转移矩阵。

## 必要的矩阵知识

### 矩阵是什么

一个 $n$ 行 $m$ 列的矩阵记作 $n\times m$ 矩阵：

$$
A=
\begin{bmatrix}
a_{11}&a_{12}&\cdots&a_{1m}\\
a_{21}&a_{22}&\cdots&a_{2m}\\
\vdots&\vdots&\ddots&\vdots\\
a_{n1}&a_{n2}&\cdots&a_{nm}
\end{bmatrix}
$$

例如，下面是一个 $2\times 3$ 矩阵：

$$
\begin{bmatrix}
1&2&3\\
4&5&6
\end{bmatrix}
$$

行数和列数相同的矩阵叫作方阵。矩阵快速幂处理的就是方阵，因为只有方阵才能连续与自身相乘。

### 矩阵乘法

设 $A$ 是 $n\times r$ 矩阵，$B$ 是 $r\times m$ 矩阵。只有当 $A$ 的列数等于 $B$ 的行数时，乘积 $C=A\times B$ 才有定义，结果是一个 $n\times m$ 矩阵。

结果中第 $i$ 行、第 $j$ 列的元素为：

$$
C_{ij}=\sum_{k=1}^{r}A_{ik}B_{kj}
$$

也就是取 $A$ 的第 $i$ 行和 $B$ 的第 $j$ 列，对应位置相乘后求和。例如：

$$
\begin{bmatrix}
1&2\\
3&4
\end{bmatrix}
\begin{bmatrix}
5&6\\
7&8
\end{bmatrix}
=
\begin{bmatrix}
1\times5+2\times7&1\times6+2\times8\\
3\times5+4\times7&3\times6+4\times8
\end{bmatrix}
=
\begin{bmatrix}
19&22\\
43&50
\end{bmatrix}
$$

矩阵乘法满足结合律：

$$
(AB)C=A(BC)
$$

这正是快速幂能够用于矩阵的原因。不过，矩阵乘法通常**不满足交换律**，即 $AB$ 往往不等于 $BA$。写代码时不能随意交换相乘顺序。

### 单位矩阵

$n$ 阶单位矩阵记作$E_n$或$I_n$。它的主对角线全是 $1$，其余位置全是 $0$：

$$
I_n=
\begin{bmatrix}
1&0&\cdots&0\\
0&1&\cdots&0\\
\vdots&\vdots&\ddots&\vdots\\
0&0&\cdots&1
\end{bmatrix}
$$

对于任意 $n$ 阶方阵 $A$，都有：

$$
AI_n=I_nA=A
$$

单位矩阵在矩阵乘法中的作用，和数字 $1$ 在普通乘法中的作用相同。因此，矩阵快速幂的答案初值必须是单位矩阵。

## 从普通快速幂到矩阵快速幂

先回顾普通快速幂。若要计算 $a^{13}$，可以把指数写成二进制：

$$
13=(1101)_2=8+4+1
$$

于是：

$$
a^{13}=a^8\cdot a^4\cdot a
$$

算法每轮考察指数的最低位。如果这一位是 $1$，就把当前底数乘入答案；随后让底数平方，并把指数右移一位。

```c++
int qpow(int a, int b, int p){
	int r = a % p;
	while(b){
		if(b & 1) r = (r * a) % p;
		a = (a << 1) % p;
		b >>= 1;
	}
	return r;
}
```

每轮都会把指数减半，所以循环次数是 $O(\log n)$。

矩阵快速幂完全沿用这套过程：

- `result = 1` 改为 `result = 单位矩阵`；
- 数字乘法改为矩阵乘法；
- 其余逻辑不变。

如果矩阵边长为 $k$，朴素矩阵乘法需要 $O(k^3)$ 时间，快速幂进行 $O(\log n)$ 次矩阵乘法，因此总时间复杂度为：

$$
O(k^3\log n)
$$

算法只需要保存少量 $k\times k$ 矩阵，空间复杂度为 $O(k^2)$。

## 如何构造斐波那契转移矩阵

只保存 $F_n$ 还不够，因为计算下一项时同时需要 $F_n$ 和 $F_{n-1}$。把它们放进同一个列向量：

$$
S_n=
\begin{bmatrix}
F_n\\
F_{n-1}
\end{bmatrix}
$$

下一步的状态是：

$$
S_{n+1}=
\begin{bmatrix}
F_{n+1}\\
F_n
\end{bmatrix}
=
\begin{bmatrix}
F_n+F_{n-1}\\
F_n
\end{bmatrix}
$$

将右侧写成矩阵乘法：

$$
\begin{bmatrix}
F_{n+1}\\
F_n
\end{bmatrix}
=
\begin{bmatrix}
1&1\\
1&0
\end{bmatrix}
\begin{bmatrix}
F_n\\
F_{n-1}
\end{bmatrix}
$$

因此，斐波那契数列的转移矩阵是：

$$
Q=
\begin{bmatrix}
1&1\\
1&0
\end{bmatrix}
$$

连续转移 $n$ 次可以写成：

$$
\begin{bmatrix}
F_{n+1}\\
F_n
\end{bmatrix}
=Q^n
\begin{bmatrix}
F_1\\
F_0
\end{bmatrix}
=Q^n
\begin{bmatrix}
1\\
0
\end{bmatrix}
$$

进一步展开可以得到一个常用结论：

$$
Q^n=
\begin{bmatrix}
F_{n+1}&F_n\\
F_n&F_{n-1}
\end{bmatrix}
\qquad(n\ge 1)
$$

所以求出 $Q^n$ 后，矩阵右上角的元素就是 $F_n$。这个写法还有一个好处：当 $n=0$ 时，$Q^0=I$，右上角仍然是 $0$，不需要单独处理边界。

## C++17 完整实现

下面沿用我平时写题的习惯：用 `Matrix` 结构体封装矩阵，`c` 存放元素，`msize` 表示矩阵大小。这里处理的是斐波那契数列，所以矩阵大小固定为 $2\times2$，不再额外写成泛型模板。

```cpp
#include <bits/stdc++.h>
using namespace std;

using ll = long long;
const int mod = 1e9+7;

struct Matrix{
	static constexpr int msize = 2;
	int c[msize][msize];
	Matrix(){memset(c, 0, sizeof c);}

	inline Matrix operator*(const Matrix &o) const{
		Matrix r;
		for(int k=0; k<msize; k++){
			for(int i=0; i<msize; i++){
				if(!c[i][k]) continue;
				for(int j=0; j<msize; j++){
					r.c[i][j] = (r.c[i][j] + (ll)c[i][k] * o.c[k][j]) % mod;
				}
			}
		}
		return r;
	}

	inline Matrix& operator*=(const Matrix &o){
		return *this = *this * o;
	}
};

inline Matrix qpow(Matrix T, ll b){
	Matrix R;
	for(int i=0; i<Matrix::msize; i++) R.c[i][i] = 1;
	while(b){
		if(b & 1) R *= T;
		T *= T;
		b >>= 1;
	}
	return R;
}

inline void qwq_(){
	ll n; cin >> n;
	Matrix T;
	T.c[0][0] = T.c[0][1] = T.c[1][0] = 1;

	Matrix R = qpow(T, n);
	cout << R.c[0][1] << '\n';
}

int main(){
	ios::sync_with_stdio(0);
	cin.tie(0); cout.tie(0);

	qwq_();
	
	return 0;
}
```

若输入：

```text
10
```

程序输出：

```text
55
```

`qpow(T,n)` 计算的是 $T^n$。其中 `R` 必须从单位矩阵开始，这样 $n=0$ 时会直接返回 $I$，右上角恰好为 $F_0=0$。矩阵元素使用 `int` 保存，乘法时先转成 `ll`，避免两个 `int` 相乘溢出。

这份程序求的是 $F_n\bmod (10^9+7)$。如果题目给出了其他模数，只需修改 `mod`；如果题目不要求取模，则还要考虑结果本身是否会超出整数类型的范围。

## 推广到一般线性递推

矩阵快速幂不只适用于斐波那契数列。考虑一个 $k$ 阶线性递推：

$$
f_n=c_1f_{n-1}+c_2f_{n-2}+\cdots+c_kf_{n-k}
$$

把最近的 $k$ 项组成状态向量：

$$
S_n=
\begin{bmatrix}
f_n\\
f_{n-1}\\
\vdots\\
f_{n-k+1}
\end{bmatrix}
$$

对应的转移矩阵为：

$$
T=
\begin{bmatrix}
c_1&c_2&c_3&\cdots&c_k\\
1&0&0&\cdots&0\\
0&1&0&\cdots&0\\
\vdots&\ddots&\ddots&\ddots&\vdots\\
0&\cdots&0&1&0
\end{bmatrix}
$$

第一行负责计算新的 $f_n$，下面的 $1$ 负责把已有状态依次向后移动。若已知 $f_0,f_1,\ldots,f_{k-1}$，那么对 $n\ge k-1$ 有：

$$
S_n=T^{\,n-(k-1)}S_{k-1}
$$

构造转移矩阵时，可以逐行问两个问题：

1. 新状态中的这个量，如何由旧状态表示？
2. 对应的系数应该放在这一行的哪一列？

把每个新状态都写成旧状态的线性组合，矩阵自然就构造出来了。

## 还有哪些题可以这样做

### 固定长度的图上游走计数

设图的邻接矩阵为 $A$。如果从点 $i$ 到点 $j$ 有一条边，就令 $A_{ij}=1$；有多条边时，可以把对应位置写成边数。

此时，$(A^k)_{ij}$ 表示从 $i$ 出发，恰好经过 $k$ 条边到达 $j$ 的游走数量。这里统计的是游走，途中可以重复经过顶点和边，并不一定是简单路径。

### 自动机与固定状态动态规划

如果一个动态规划每一步都使用相同的线性转移，而且状态数量较少，就可以把一次转移写成矩阵。执行 $n$ 步相当于乘上转移矩阵的 $n$ 次幂。

字符串自动机计数、有限状态方案数统计等问题，经常使用这种思路。

### 带常数项的递推

递推式中出现常数也能处理。例如：

$$
f_n=af_{n-1}+b
$$

在状态末尾补一个恒为 $1$ 的量：

$$
\begin{bmatrix}
f_n\\
1
\end{bmatrix}
=
\begin{bmatrix}
a&b\\
0&1
\end{bmatrix}
\begin{bmatrix}
f_{n-1}\\
1
\end{bmatrix}
$$

多出来的这一维把常数项变成了普通的线性转移。

## 容易写错的地方

### 1. 指数偏移一位

如果初始状态是 $S_1$，目标是 $S_n$，通常需要乘 $T^{n-1}$，而不是 $T^n$。最稳妥的办法是令目标下标等于初始下标，检查此时指数是否为 $0$。

### 2. 答案没有初始化为单位矩阵

快速幂从指数 $0$ 开始累积，矩阵的零次幂是单位矩阵。把答案初始化为零矩阵，会让之后的结果始终为零。

### 3. 交换矩阵相乘的顺序

矩阵乘法没有交换律。使用列向量时，通常写作 $S_{n+1}=TS_n$；如果改用行向量，矩阵的位置和结构都要相应调整。整篇推导必须使用同一种约定。

### 4. 乘法过程中溢出

不能等三层循环结束后再统一取模。两个元素相乘和每次累加时都要控制范围。若模数接近 `long long` 的上限，中间乘积仍可能溢出，需要使用安全模乘；在支持 `__int128` 的编译器中，也可以用它保存中间结果。

### 5. 把“游走”写成“简单路径”

邻接矩阵幂允许顶点和边重复出现。若题目要求不能重复经过顶点，通常不能直接套用邻接矩阵快速幂。

### 6. 状态不够完整

状态向量必须包含计算下一步所需的全部信息。若递推还依赖前缀和、常数项或其他辅助量，就要把它们一起加入状态。

## 怎样检查自己的模板

不要只用一个大样例测试。先检查最小的几个输入：

| $n$ | $F_n$ |
|---:|---:|
| 0 | 0 |
| 1 | 1 |
| 2 | 1 |
| 3 | 2 |
| 10 | 55 |

随后写一个 $O(n)$ 的朴素递推，在较小范围内逐项比较两个算法的结果。随机对拍很容易发现指数偏移、初始状态和矩阵方向等问题。

## 练习

1. 用矩阵快速幂求递推 $f_n=2f_{n-1}+3f_{n-2}$ 的第 $n$ 项。
2. 为 Tribonacci 数列 $T_n=T_{n-1}+T_{n-2}+T_{n-3}$ 构造 $3\times3$ 转移矩阵。
3. 给定一张有向图，统计从点 $s$ 到点 $t$、长度恰好为 $k$ 的游走数量。
4. 将递推 $f_n=af_{n-1}+bn+c$ 转化为矩阵。提示：状态中除了 $f_n$，还需要保存 $n$ 和常数 $1$。

## 总结

矩阵快速幂适合处理这样的题：状态数量固定，每一步使用相同的线性转移，而步数非常大。

实际解题时可以按下面的顺序思考：

1. 选出能够完整描述一次转移的状态；
2. 把新状态写成旧状态的线性组合；
3. 根据系数构造转移矩阵；
4. 确定初始状态与幂指数，特别检查下标偏移；
5. 使用矩阵快速幂，并处理取模与溢出。

快速幂部分往往只是固定模板。能否准确设计状态、写对转移矩阵，才是这类题真正的难点。
